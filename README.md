# Mock-Hackathon
Phillip and Kevin mock hackathon

- `backend/`: FastAPI + PostgreSQL API. Setup and endpoints are in [backend/README.md](backend/README.md).
- `frontend/`: React + Vite app that volunteers use to check visitors in.
